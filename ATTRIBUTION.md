# Attribution

## Paywall 3D rock hand

The 3D model on the paywall (`HiddenJams/Resources/RockHand.usdz`) is original
work made for this app. It is generated procedurally from the scripts in
`Tools/RockHandModel/` and uses no third-party meshes, textures or artwork, so
it needs no attribution.

## Paywall rock-hand fallback image

The flat rock-hand image (`HiddenJams/Assets.xcassets/RockHand.imageset`) is
shown only if the 3D model fails to load. It is derived from the "sign of the
horns" emoji (U+1F918 🤘) in
[Noto Emoji](https://github.com/googlefonts/noto-emoji) by Google.

The emoji's hand silhouette (Apache 2.0) was extruded into 3D with Blender and
rendered as a glossy orange charm for this app. No other Noto Emoji artwork is
used.
